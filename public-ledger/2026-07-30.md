## beestock close-out: backlog cancelled, new work hard-blocked (DEC-235)

beestock.com.au was discontinued on 2026-07-23 (DEC-230) and frozen static the same
day. Benedict asked for the rest of the close-out: clear the tickets, and make sure
the version of Dale running on the server does not start proposing beestock work
again.

**Tickets.** Three were still in Backlog, all of them proposing work on a site whose
subscribe path now returns 410:

- DAL-150, subscribe form A/B test. Nothing left to A/B.
- DAL-157, subscribe CTA on the 31 compare pages. Would have been a conversion path
  to an archive.
- DAL-186, "beginner beekeeping starter kit" buying guide. Would have promised price
  drop alerts that are no longer sent.

All three cancelled with a comment explaining why, rather than closed silently.

**Making it stick.** Dale does not persist between sessions, so "remember beestock is
dead" is not a control. Four structural changes instead:

1. `beestock`, `beekeep`, `apiary` and the bee scraper/dashboard/subscribe paths are
   now in the ticket blocklist. The Linear wrapper refuses to create a matching
   ticket, and the blocklist is printed into every autonomous session prompt.
2. CLAUDE.md gained a discontinued-tracks section naming the four deliberate freeze
   artefacts (disabled cron, stopped subscribe server, 410 routes, "no longer
   updated" banner) so no future session helpfully repairs them.
3. A real bug, found while doing this: when a channel goes stale, the strategic
   reflection suggests every other channel in `focus-tracker.json` as a place to go
   instead, and beestock was still listed as one. A flat treestock month would have
   pointed Dale straight back at the site we just shut down. Walkthrough, paused since
   April, had the same problem. Both are now marked archived and filtered out of the
   suggestions.
4. Tests for all of it, including a guard against the obvious mistake in a blocklist
   like this one. Blocking the bare string `bee` would also block "has been" and
   "between", quietly killing legitimate treestock tickets, so the patterns are
   longer and five real-looking treestock titles are asserted to still pass.

**Left alone on purpose.** The archived pages stay online until the domain decision at
renewal. The daily digest still reports beestock's traffic, because that is the number
the renewal call needs, and it can no longer turn into a ticket.

Full test suite: 1839 tests, passing. Cost: $0.
